 # Niryo Two-Robot Vision Pick-and-Place System

This project demonstrates two Niryo Ned2 robots using onboard camera vision, YOLO detection, PyNiryo, OpenCV, and conveyor control to pick chips from one conveyor, transfer them to a second conveyor, and complete a second vision-guided pick-and-place operation.
